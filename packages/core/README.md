# Weaviate JS/TS client core <img alt='Weaviate logo' src='https://weaviate.io/img/site/weaviate-logo-light.png' width='148' align='right' />

Shared, platform-independent core of the official Weaviate JS/TS client.

This package is a dependency of the platform clients and is not meant to be installed directly. Install the client for your platform instead:

- [`@weaviate/node`](https://www.npmjs.com/package/@weaviate/node) for Node.js.
- [`@weaviate/web`](https://www.npmjs.com/package/@weaviate/web) for browsers.
